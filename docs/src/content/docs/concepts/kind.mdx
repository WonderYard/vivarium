A kind is a way to group elements that share common behavior. Unlike elements, kinds have no color and cannot appear directly on the grid. They exist to reduce duplication and make rule definitions more expressive.

## Creating a kind

```typescript
const conductor = vi.kind("conductor");
```

The name must be unique across all elements and kinds.

## Extending a kind

Elements extend a kind by passing it in an array when they are created:

```typescript
const conductor = vi.kind("conductor");

const wire = vi.element("wire", "orange", [conductor]);
const head = vi.element("head", "blue", [conductor]);
const tail = vi.element("tail", "white", [conductor]);
```

An element can extend more than one kind:

```typescript
const organic = vi.kind("organic");
const living = vi.kind("living");

const tree = vi.element("tree", "green", [organic, living]);
```

## Defining rules on kinds

Rules can be defined on a kind just like on an element. When a rule is defined on a kind, it applies to every element that extends that kind, with lower priority than rules defined directly on the element.

```typescript
const conductor = vi.kind("conductor");

const empty = vi.element("empty", "black");
const wire = vi.element("wire", "orange", [conductor]);
const head = vi.element("head", "blue", [conductor]);
const tail = vi.element("tail", "white", [conductor]);

// This rule applies to wire, head, and tail
conductor.to(empty).count(empty, 8);
```

## Using kinds in conditions

Kinds can be used in `count` and `is` conditions. When a condition checks for a kind, it matches any element that extends that kind.

```typescript
// Count all conductors in the neighborhood
empty.to(wire).count(conductor, 2);

// Check if a specific neighbor is a conductor
empty.to(wire).is(vi.neighbor.TOP, conductor);
```

This is useful when you want a condition to match a group of elements without listing each one individually.
